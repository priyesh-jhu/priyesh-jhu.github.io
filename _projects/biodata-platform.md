A full-stack platform for analyzing and visualizing large-scale biological datasets, built for research teams.

## Features

- Interactive data exploration with real-time filtering
- Automated statistical analysis pipelines
- Role-based access control for multi-team collaboration
- REST API for programmatic access

## Technical Highlights

- Python/FastAPI backend with PostgreSQL
- React frontend with D3.js visualizations
- Containerized with Docker Compose
- CI/CD with GitHub Actions
