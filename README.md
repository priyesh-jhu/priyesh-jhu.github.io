# priyeshagrawal.github.io

Personal portfolio website built with Jekyll and hosted on GitHub Pages.

## Local Development

```bash
# Install dependencies
bundle install

# Serve locally
bundle exec jekyll serve
```

Visit `http://localhost:4000` to preview.

## Deployment

Push to the `main` branch — GitHub Pages will build and deploy automatically.

## Customization

- **Content:** Edit markdown files in the root and `_projects/` directory
- **Styling:** Modify `assets/css/style.css`
- **Config:** Update `_config.yml` for site-wide settings
